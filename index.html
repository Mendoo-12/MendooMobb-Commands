GitHub publishing

Changes are a preview until you click Save & Publish. Publishing requires a repository-scoped GitHub token, entered only when editing. Do not use this editor on an untrusted/shared device.

Categories — rename, reorder, delete

Drag ☰ to change the order of categories. Rename a category to update every command inside it.

Command order

Drag ☰ to arrange commands. Choose All to set the full website order, or a category to rearrange just its commands. The public directory defaults to your saved order.
